# НЕ КЛЮЙ

Интерактивный проект о цифровом финансовом мошенничестве для жителей Краснодарского края.
Краевой конкурс «На волне финансов» (Кубанский государственный аграрный университет), 2026.

## Что внутри

| Блок | Файл | Что делает |
|---|---|---|
| Дозор | `src/bot.js`, `src/data/signals.js` | разбор подозрительного сообщения: 33 признака, 153 формулировки, оценка риска, подсветка находок |
| Тренажёр | `src/trainer.js`, `src/data/quiz.js` | 10 ситуаций для двух аудиторий, объяснение после каждого ответа |
| Вход на сайт | `src/gate.js`, `src/extra.css` | обычное окно входа (Госуслуги / Google) без пометок «демо»; после входа — настоящие IP и провайдер, устройство, экран, язык и «профиль аккаунта» |
| Симулятор звонка | `src/phone.js`, `src/audio/*.mp3` | 3D-iPhone 18 Pro Max в бургунди: широкая площадка камер, титановая рамка, стеклянный экран. Заставка «спиной → мелко дрожит → переворачивается» → **экран блокировки iOS** (часы, дата, три уведомления, «свайп вверх») → входящий вызов. Телефон можно взять и крутить мышью; диалог с «оператором» — 5 финалов, голос мужской или женский, проходит телефонную обработку, есть регулятор громкости и сигнал отбоя |
| Скрипт изнутри | `src/index.html` (секция `#case`) | настоящий скрипт кол-центра по шагам: приём, цель, заготовки ответов, карточка оператора |
| Маркерные выделения | `src/extra.css` (`.hl`) | ключевые слова подчёркнуты «маркером»: цвет = тип угрозы |
| Волна и река денег | `src/scene.js`, `src/extra.css` (`.river`) | three.js: частицы волны + поток монет; поверх — фигуры «жертва → мошенник» |
| Тексты | `src/index.html` | механика обмана, аудитории, методика занятия, куда обращаться |

Сборка статическая: нет фреймворков, нет CDN, нет аналитики и куки. Сайт открывается офлайн —
это важно для показа на финале по видеоконференции. Единственный сетевой запрос — определение
IP-адреса и провайдера в окне входа (`ipwho.is`, резерв `ipinfo.io`): без него нельзя показать
настоящие данные. Ничего из увиденного не отправляется и не сохраняется.

## Где смотреть

Живой сайт: **https://mouselegend37.github.io/ne-kluy/**

Публикуется автоматически: любой коммит в ветку `main` собирается на GitHub Actions
и уезжает на GitHub Pages за минуту (`.github/workflows/pages.yml`). Руками ничего
заливать не нужно — правим `src/`, коммитим, смотрим результат по ссылке.

## Запуск

```bash
npm install        # один раз
npm run dev        # сборка + локальный сервер → http://localhost:5173
npm run build      # только сборка в dist/
node serve.mjs     # раздать готовый dist/ на 127.0.0.1:5173
```

`dist/` — самодостаточная папка: `index.html`, `app.js`, `app.css`, шрифты в `assets/`.
Её можно положить на любой статический хостинг или отдать с флешки.

## Инструменты

Всё бесплатное, без ключей и подписок; лежит в `tools/`, в сборку не попадает.

| Файл | Что делает |
|---|---|
| `tools/polyhaven.py` | библиотека 3D-ассетов Poly Haven (CC0, 522 модели, HDR-карты, PBR-текстуры): поиск, скачивание моделей в glTF, HDRI → маленькая equirect-картинка |
| `tools/tts.py` | озвучка скрипта: `--engine edge` (Microsoft Neural, нужен интернет) или `--engine piper` (локально, офлайн); `--suffix=-f` — женский вариант тех же реплик |
| `tools/voice-compare.py` | сравнение голосов на одной фразе → `tools/voice-sample/` |
| `tools/voice-compare.html` | страница с тремя дорожками для прослушивания в браузере |
| `tools/figma-plugin/` | локальный плагин Figma: выделение → JSON и JSON → фреймы |
| `tools/figma.mjs` | Figma REST API: список фреймов и выгрузка макетов в PNG/SVG |
| `tools/figma-mockup.mjs` | макет экрана вызова для Figma (JSON для плагина + SVG) из констант `phone.js` |

Карта окружения телефона — настоящая HDR-карта Poly Haven (`brown_photostudio_02`, тёплый
фотостудийный свет под бургунди), ужатая до `src/assets/env-studio.jpg` (26 КБ): металл
ловит реальные блики, а не нарисованный градиент.
Подключение Figma — [`docs/FIGMA.md`](docs/FIGMA.md).

## Проверки

- Консоль браузера: без ошибок.
- Вёрстка без горизонтального скролла, адаптив от 360 px.
- `prefers-reduced-motion`: волна статична, появление блоков отключено.
- Кнопка «Крупный текст» (аудитория 60+) увеличивает кегль и контраст.
- Клавиатурная навигация: все действия — на `<button>`/`<a>`, есть скип-ссылка.

## Технические заметки

- Сборка: `esbuild` (без фреймворков). JS ≈ 650 КБ до сжатия — это three.js; при gzip ≈ 160 КБ.
- Стили разделены: `styles.css` — базовая система, `extra.css` — маркер, река, шлюз, телефон.
- Диалог звонка — конечный автомат (`NODES` в `phone.js`); у каждой ветки свой финал,
  запоздавшие реплики отсекаются счётчиком «поколения», чтобы «Начать заново» не смешивало ветки.
- Логотип Госуслуг — официальный знак, который прислал автор: `src/assets/gosuslugi.png`
  (обрезан по контуру, белый фон переведён в прозрачность, чтобы знак жил на тёмной кнопке).
- Голос мошенника — нейросетевой (edge-tts, мультиязычный `en-US-AndrewMultilingualNeural`,
  русский читает живее старого `ru-RU-DmitryNeural`; сравнение голосов — `tools/voice-compare.html`). Файлы лежат
  в `src/audio/`, собираются скриптом `python tools/tts.py` и попадают в `dist/assets`.
  Тем же скриптом можно переозвучить всё локальным Piper (`--engine piper`) — офлайн,
  без интернета и ключей; голоса лежат в `tools/voices/`.
  Если звук не проигрался (нет драйвера, старый браузер), диалог всё равно идёт: текст на месте.
- Голос идёт через телефонный тракт на WebAudio: срез 310–3400 Гц, подъём разборчивости
  на 1,9 кГц, мягкое насыщение и компрессия; громкость — регулятор в панели разговора.
  Отбой — синтезированный сигнал 425 Гц (три гудка), как в обычной телефонии.
- Телефон можно взять и повернуть: тянуть мышью или пальцем до ±60° по горизонтали и
  ±35° по вертикали; после отпускания и ухода курсора он плавно возвращается.
  Двойной клик — сброс положения. Пока курсор не наведён, аппарат мелко дрожит.
- Экран не плоская наклейка: отдельный слой стекла с отражением студии, тень по краям,
  диагональный блик и перспективный параллакс между стеклом и интерфейсом.
- Заставка телефона: спина с яблоком и блоком камер → дрожь и расходящиеся кольца вызова →
  переворот экраном к человеку. Ролик идёт по таймлайну (`TIMELINE` в `phone.js`), запускается,
  когда секция появляется в кадре, и полностью отключается при `prefers-reduced-motion`.
- Телефон масштабируется по `ResizeObserver` от собственного прямоугольника холста:
  размер буфера отрисовки и CSS-размер совпадают, иначе модель «сплющивается».
- Телефон — не «телефон вообще», а iPhone по геометрии: корпус 1.90 × 3.92 (отношение
  0.485 — как 71.6 × 147.6 мм у iPhone 15/16), экран 1.75 × 3.75, скругления, боковые
  кнопки, титановая рамка, динамический остров с камерой (при соединении расширяется
  и пульсирует зелёным). Дизайн-сетка экрана 512 × 1097, текстура ×2 — интерфейс
  не растягивается, потому что пропорции плоскости и текстуры совпадают.
- Кнопки «Ответить» / «Отклонить» / «Завершить» нажимаются **на самом экране**: указатель
  переводится в координаты дизайн-сетки рейкастом по плоскости экрана, поэтому попадание
  не зависит от поворота модели и размера окна. При наведении поворот «замерзает»,
  чтобы по кнопке можно было попасть курсором. Для клавиатуры и скринридеров рядом лежат
  настоящие `<button>` (`.call__keys`, визуально скрыты через `clip-path`).
- Кнопка «Войти через Госуслуги» ничего не отправляет: все «утекшие» данные собраны
  в браузере (`navigator`, WebGL, `Intl`) плюс вымышленный профиль. Проверено:
  0 запросов fetch/XHR после загрузки.
- Настоящий публичный IP при включённом VPN не виден никому — трафик уже вышел из туннеля
  на чужой стороне. Поэтому в окне входа показывается ещё и адрес устройства в локальной
  сети (WebRTC ICE-кандидат): VPN его не подменяет. Chrome по умолчанию отдаёт mDNS-имя
  вместо номера — так и подписано: «имя в локальной сети».
- После перезагрузки страница больше не «прыгает» в середину: `history.scrollRestoration =
  "manual"`, позиция запоминается при открытии окна входа и возвращается при закрытии.
- Появление блоков повторяется при каждой прокрутке: класс `is-in` снимается, когда блок
  ушёл из виду, поэтому анимация проигрывается и сверху, и снизу.
- В регулярках движка нельзя использовать `\w` и `\b` для кириллицы — в JS они работают только
  с латиницей. Все русские шаблоны написаны через явные классы `[а-я]`.
- Веса признаков: 1 — контекст, 2 — характерный признак, 4 — решающий.
  Оценка = сумма весов × 12, потолок 100. Уровни: <20 низкий, <45 средний, <70 высокий, иначе критический.
